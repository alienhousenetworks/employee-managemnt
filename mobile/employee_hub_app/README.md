## Flutter Employee Hub client

This directory contains the Dart client sources and package manifest. Generate local platform runners before the first run:

```bash
flutter create . --platforms=android,ios
flutter pub get
flutter analyze
flutter test
flutter run
```

Enter the HTTPS Frappe/ERPNext URL and sign in with an ERPNext account. The API session cookie is held in app memory; only the site URL and username are saved in preferences. For production, verify session expiry/logout, secure platform storage, app signing, deep-link policy and transport security. Platform runner files are generated locally and are not committed in this starter.
